# LinearB Test Pipeline

Este projeto simula uma pipeline de CI/CD com métricas para testes.

## Scripts
- `npm install`: Instala as dependências
- `npm test`: Roda os testes com Jest

## Endpoints simulados
- `hello()`: Retorna mensagem de boas-vindas
- `sum(a, b)`: Soma dois números

## CI/CD
Utiliza GitHub Actions para testes automáticos
